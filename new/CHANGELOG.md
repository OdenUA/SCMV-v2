## v 2.4.1 — 2026-10-21

## v 2.4.0 — 2026-10-21

- Переключатель «Топливо» убран. Запрос `Fuel Litres` отправляется автоматически вместе с загрузкой телеметрии (кнопка «Телеметрия», дашборд) и сырого трека (кнопка «Сырой», админка) — дополнительных запросов в БД нет.
- Вкладки «Заправки и сливы»/«Сводка по бакам»/«Суточная таблица» и KPI-бейджи «Расход топлива»/«Моточасы» видны всегда; без загруженных данных — заглушки «Нет данных топлива».
- Смена ТС/дат очищает данные топлива (перезапрос — со следующей загрузкой телеметрии).

## v 2.3.8 — 2026-10-21

## v 2.3.7 — 2026-10-21

- Бейдж «Расход топлива» на верхней панели дополнен средним расходом на 100 км: формат «53.0 л · 31.4/100км» (значение из сводки по бакам; при отсутствии пробега показываются только литры).

## v 2.3.6 — 2026-10-21

- Топливо: защита детектора от колебаний датчика уровня:
  - слив отклоняется, если уровень вернулся в течение 30 минут после события (возврат ≥60% объёма) — колебание всегда возвращается, реальное событие нет;
  - «слив» во время движения (>10 км/ч) принимается только при объёме ≥ двойной нормы расхода (2×30 л/ч за длительность события) — физический слив на ходу невозможен;
  - компенсированные пары «слив → заправка» в одной точке (≤300 м, ≤45 мин, объёмы ±35%) отменяются как колебание, в консоли помечаются `[fuel] компенсированная пара`.
- Проверено на реальных данных устройства 1699: genuine-события сохраняются.

## v 2.3.5 — 2026-10-21

- Топливо: фильтр одноточечных выбросов датчика. Точка, отклоняющаяся от линейной интерполяции между соседними точками на ≥5 л при близких значениях самих соседей, отбрасывается до детекта событий. Устранены ложные «сливы»/«заправки» от кратковременных сбоев датчика — такой провал виден только в таблице событий, на плотном графике он неразличим.

## v 2.3.4 — 2026-10-21

- Верхняя панель (KPI): бейджи «Расход топлива, л» (янтарный) и «Моточасы, ч» (голубой). Видны только при включённом тогле «Топливо»; значения — из сводки по бакам текущего периода, при выключении/очистке — прячутся и сбрасываются.

## v 2.3.3 — 2026-10-21

- События топлива отображаются на карте: маркеры заправок (зелёные) и сливов (красные) со всплывающими попапами (тип, время, объём, координаты). Отдельный слой `fuelLayerGroup`, очищается при выключении тогла/смене данных.
- Клик по событию в таблице «Заправки и сливы»: фокус карты на маркер события (zoom ≥14, попап) + вертикальная янтарная пунктирная линия времени события на графике телеметрии. Клик по маркеру на карте тоже ставит линию на графике. Линия события сбрасывается при загрузке нового трека/топлива.

## v 2.3.1 — 2026-10-21

## v 2.3.0 — 2026-10-21

- Отчёт по топливу в дашборде и админке (мониторинг): кнопка-тогл «Топливо» рядом с «Телеметрией». Вкл — показываются вкладки и выполняется запрос `Fuel Litres`; выкл — всё связанное с топливом скрыто и запрос НЕ выполняется (состояние в localStorage `dt_fuel_enabled`).
- Панель телеметрии: линия уровня топлива (пунктир, правая ось «литры»), значения интерполируются по времени на ось трека.
- Вкладки: «Заправки и сливы» (Дата/время, Тип, Объём, Координаты), «Сводка по бакам» (начало/заправки/сливы/конец/расход/пробег/моточасы/ср. расход), «Суточная таблица» с итоговой строкой.
- Алгоритмы по мотивам standalone Fuel Report: мин. объём события 10 л, слияние шагов одного направления ≤10 мин, GPS-разрывы 5 мин/3 км, слив засчитывается только если превышает норму 30 л/ч (иначе — расход); шаги со скоростью изменения ≤30 л/ч считаются обычным расходом и не размывают события.
- Запрос топлива автоповторяется при смене ТС/дат (только при включённом тогле).

## v 2.2.2 — 2026-10-21

- Слой локаций: на карте отображаются только локации, входящие в маршрут выбранного ТС за выбранный период (по координатам пробега и трека). Без загруженного маршрута локации не показываются; пересчёт при загрузке пробега/трека и при очистке.
- Вхождение в маршрут считается по радиусу `LOCATION_RADIUS_M = 500` м вокруг точки локации (не точное совпадение): быстрая предпроверка по bounding-box, затем haversine. Радиус — константа в `js/core/config.js`.

## v 2.2.1 — 2026-10-21

- Индикатор статуса ТС определяется по времени последней активности (sdate), а не по полю «контроль» (оно не отражает связанность: у простаивающих трекеров ON, у работающих OFF). Три уровня: зелёный — активность ≤30 минут, жёлтый — в пределах недели, красный — больше недели (подсказка в title точки).

## v 2.2.0 — 2026-10-21

- При построении маршрута дополнительно отправляется запрос `Startstop accumulation / act: reinit` — в ответе приходит справочник локаций (cols поля `marker`: key → название, координаты, адрес, иконка).
- Локации отображаются на карте отдельным слоем: POI-маркеры с постоянными подписями-названиями и попапами (название, адрес, координаты).
- В таблице «Остановки» числовое поле Marker заменяется названием локации при совпадении ключа (как у fleet); `0`/пусто — пустая ячейка.
- В попапе стоянки добавлена строка «Локация: …» при совпадении.
- Справочник подхватывается также из cols любого ответа Startstop accumulation; таблица и маркеры стоянок перерисовываются при его получении.

## v 2.1.0 — 2026-10-21

- Новый интерфейс дашборда (TelemaRoute Analytics) по макету: тёмная тема, панель управления справа.
- Проигрыватель трека: play/pause/reset, скорости 1x/2x/5x/10x, слайдер времени, маркер с поворотом по азимуту.
- График скорости (Chart.js) с синхронизацией маркера на карте по hover.
- Перенесён функционал SCMV v2:
  - Vehicle Select Min: карточки ТС, поиск, фильтры Онлайн/Офлайн, авто-режим.
  - Треки: обычный (полилиния) и сырой (точки), chunked-отрисовка.
  - Аномалии: Time Gap / Speed Spike / Position Jump / Out of Bounds, слои на карте, таблица, SQL для удаления (покадневный DELETE + recalcstartstop), массовое удаление.
  - Стоянки (Start/Stop Accumulation): таблица + маркеры (короткие ≤5 мин).
  - Пробег (Mileage Report): сегменты, пропуски (красный пунктир), старт/финиш.
  - Dev Log: Device Alarm / Device Log / Full Device Track (чанкинг ≥14000), интервальный отчёт (типы 1–4), SQL из GPS-аномалий.
  - Анализ маршрута: мало спутников / низкое напряжение / движение без питания / аномалии трека / скачки высоты; сводка и хронология, hide-ok.
  - Ручной маршрут (до 25 точек, OSRM, ссылка Google Maps), track-cut (✂️ SQL по двум точкам).
  - Настройки аномалий (пороги + тексты буферов РЕБ/вкл/выкл/ok).
  - Экспорт таблиц в Excel (SheetJS), виртуализированные таблицы.
- Админ-панель в едином дизайне (admin.html):
  - Список ТС (Device List): поиск, фильтры, возрастные категории, сортировка, экспорт xls, редактирование (Vehicle Edit Distribution).
  - Edit Vehicle / Edit Device / Device Status (с исправлением захардкоженных учёток v2).
  - Аудит изменений (diff в новой вкладке, XLSX).
  - Отчёты: месячный и недельный пробег (очередь запросов, прогресс, XLSX).
  - Cleanup аномалий >3000 км → SQL.
  - Мастер пакетного добавления пары «устройство + ТС» (вставка из Excel, автопривязка deviceid).
- Инфраструктура верификации: mock WS-сервер на capture-данных v2, smoke-тест через Chrome CDP, синтакс-проверка.
